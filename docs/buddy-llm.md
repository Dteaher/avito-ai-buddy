# Buddy с локальной LLM

Buddy помогает стажёру понять правило, сверить результат и сформулировать объяснение для команды. В карточке сохранённой записи можно продолжить разбор того же прогона. Кнопка источника открывает нужный запрос с его статусом, сравнением и сырым JSON.

## Решения по итогам сравнения

| Продукт | Наблюдение по документации | Решение для Buddy |
| --- | --- | --- |
| Atlassian Rovo | Ответы на вопросы сопровождаются источниками, доступ ограничен правами пользователя. | Сервер разрешает ссылки только на инструкцию открытой задачи и ответ из прогона этой задачи. [Документация Rovo](https://support.atlassian.com/rovo/docs/chat-actions/) |
| GitHub Copilot Chat | Вопросы привязаны к открытым или явно указанным материалам проекта. | В интерфейсе виден контекст прогона. Продолжение диалога сохраняет последние реплики в пределах задачи. [Документация Copilot](https://docs.github.com/en/copilot/how-tos/copilot-on-github/chat-with-copilot/get-started-with-chat) |
| Postman Agent Mode | Помощь при написании проверок использует уже полученный ответ API. | Buddy получает фактический статус, ожидание и результат сравнения. Запуск прогона и подтверждение записи остаются действиями стажёра. [Документация Postman](https://learning.postman.com/docs/tests-and-scripts/write-scripts/test-scripts) |
| Intercom Fin | Команда может прогонять набор вопросов и проверять, какие источники используются в ответах. | `pnpm eval:buddy` показывает результат по каждому вопросу и печатает ответ для проверки человеком. [Документация Fin](https://www.intercom.com/help/en/articles/7120684-fin-ai-agent-explained) |

## Воспроизведение

1. Включи локальную модель по [README](../README.md#режимы-buddy).
2. Выполни `pnpm eval:buddy`. Скрипт создаёт прогоны в SQLite в памяти, передаёт модели синтетические данные и проверяет режим ответа, тип, ссылки и текстовые признаки ожидаемых фактов. `pnpm eval:buddy --holdout` запускает дополнительный набор формулировок.
3. Открой одну из задач в браузере. Спроси, как её проверить, затем выполни проверку. Нажми **Разобрать результат**, открой источник, опубликуй запись и задай уточняющий вопрос уже на странице записи.

Проверка формата и доступности источника выполняется программно. Текстовые проверки покрывают конкретные факты. Полные ответы печатаются для ручного просмотра. Оба набора использовались при доработке подсказок модели. Эффект обучения на стажёрах требует отдельного исследования.
