## Воспроизведение

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm coverage
pnpm build
```

Прошли **112 тестов**. Покрытие строк **82,00% (1764 из 2151)** рассчитано Vitest 4.1.12 с V8 по `src/`, `server/` и `shared/`. HTML и JSON формируются в локальном каталоге `coverage/`. [Сводка измерения](coverage.json)

Для независимых наборов фраз используйте `pnpm eval:hardening --transfer --guide-only` и `pnpm eval:hardening --transfer` с настроенным провайдером. Наборы и критерии лежат в [скриптах оценки](../../scripts). Оценка относится к указанным примерам и модели.

## Как измерить пользу

Дайте стажёрам незнакомые сопоставимые поручения. Для одной группы используйте Buddy, для другой — инструкцию и обычный API-клиент. Сохраните первый запрос до подсказки, правильность вывода, время до пригодной записи и обращения к наставнику. Затем предложите обеим группам новое поручение без подсказки, чтобы проверить перенос навыка. Наставники оценивают обезличенные записи по одной шкале.

Пока проверены воспроизводимость прототипа и технические сценарии на синтетических данных. Доля вопросов и расхождений на демо не измеряет эффект на сотрудниках.
