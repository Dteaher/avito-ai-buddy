## Независимый запуск

Среда — Windows 11, Node.js 24.22.1, pnpm 11.25.0, Chrome 157.0.8103.51. Точную версию извлекли в отдельно созданный Git worktree без `.env`, `.data` и `node_modules`. Затем выполнили `pnpm install --frozen-lockfile`, `pnpm build` и запустили команду из `pnpm start`. Для параллельных проверок использовали отдельный порт и временную SQLite.

- **Справка и ручной режим.** В Chrome на 1440×900 пройдены ввод с клавиатуры, черновик, запуск, смешанный вывод, публикация, возврат, повтор, ссылка на сырой ответ, исправление по повтору и приёмка. Сессия и обе записи пережили перезапуск. Другой стажёр получил отказ. На 390×844 пройдены SEARCH-01 и ручной SORT-01 с reduced motion и нулём запросов Buddy.
- **Реальная модель и тайм-аут.** Обе задачи дошли до публикации с локальной Qwen. На 320 px проверена ширина рабочей формы. HTTP-имитатор показал ожидание, переход к справке и сохранение ввода при тайм-ауте 2 с. Задержанный ответ при смене выбранного прогона не изменил новый экран.
- **Автоматизация.** Сборка, проверка типов, ESLint, `pnpm test` и `pnpm coverage` прошли. 97 тестов, 87,20% строк (1063 из 1219). [Сводка Chrome](evidence-browser.json) · [покрытие](evidence-coverage.json) · [снимок повтора](../screenshots/first-check-evidence.png)

## Пилот и эффект для людей

Два задания для пилота используют одинаковую структуру. В первом без фильтра должны прийти пункты доставки типов A и B, а фильтр A оставляет только A. Дефект скрывает B в выдаче без фильтра. Во втором без фильтра должны прийти активные и архивные товары, а фильтр активных оставляет только их. Дефект скрывает архивные товары в выдаче без фильтра. В каждом задании два запроса и одна контрольная выдача. Команда подставляет разрешённые синтетические или обезличенные данные. В условии A участник получает инструкцию команды и обычный API-клиент. В условии B получает ту же инструкцию и Buddy. Распределение задач меняется независимо от порядка A/B и B/A. Оба условия требуют одинаковую запись с запросом, ожиданием, фактом и выводом. До сравнения участники получают одинаковое знакомство с форматом записи.

Наблюдатель отмечает пригодность первого запроса до получения результата, правильность вывода, активное время до воспроизводимой записи и фактическое обращение к наставнику. Копирование и ожидание модели можно учитывать отдельно. Два проверяющих оценивают обезличенные записи по общей шкале. Эффект для стажёров ещё предстоит измерить.
