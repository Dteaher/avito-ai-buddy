Команды `pnpm install --frozen-lockfile`, `pnpm build` и `pnpm start` запускают веб-приложение и отдельный HTTP-трекер на loopback. Для первого прохода используется демо-справка. ## Самостоятельность

Использован [протокол предыдущей итерации](first-check-transfer.md#проверка-с-участниками). В техническом прогоне ACTIVE-01 браузер сначала выбрал `status=active`, отметил ожидание «только активные» и сохранил первый вариант. Снимок зафиксировал `first.checkId=active-only` и `help=none`. После получения HTTP 200 Buddy сверил утверждение про лишний архивный товар. Наставник открыл сырой ответ, воспроизвёл проверку и принял запись без запроса уточнений.

В прогоне с обрывом автоматический сценарий довёл запись до готовности к открытию примерно за 0,7 с от открытия поручения и до получения квитанции за 1,2 с, включая перезапуск. Это время исполнения заранее заданных действий браузера. Эффект на людях ещё не измерен. Для замера нужны независимые стажёры и наставники, незнакомое сопоставимое поручение и оценка обычным API-клиентом по этому же протоколу.
